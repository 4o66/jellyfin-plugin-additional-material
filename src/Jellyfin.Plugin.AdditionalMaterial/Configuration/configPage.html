Additional Material

Download buttons and a contents view for course material stored beside your videos.

Libraries

The plugin only looks in the libraries ticked here.

Downloads

Users without it see the button disabled. This is the permission Jellyfin's own Download button uses.
How long a download has to start after the button is pressed.

Where material comes from

  • additional-material.zip in a series (course) or season (section) folder
  • <video file name>.material.zip beside an episode (lesson) or movie

Show material from lower levels on

On a course or section page, the button then lists the archives below it, with links to each lesson.

Icons

Button style

Used for the plus in the two-color style. Jellyfin's own accent is #00A4DC.

Contents view

A zip inside an archive (for example a lab pack) can then be opened in the Contents view and its files downloaded one by one.

Build archives

Uses the helper script's rules: lesson files go with their lesson, section and course files with their section and course, and programs, scripts and documents with macros or embedded code are replaced by a note. Courses that already have archives (made by hand or by the script) are left as they are.
Otherwise an archive is built the first time someone downloads it. Archives are rebuilt when their files change.

Where built archives go

One-file material

A lesson whose only material is one PDF downloads as that PDF.
Only when zipping makes it noticeably smaller: the plugin checks a sample of the file, and never zips formats that are compressed already (images, Office files, video, zip).

Folder index

The plugin remembers which folders hold material, re-reading them after every library scan. Re-read now after adding or changing zips.

Built archives

Rebuilds every archive the plugin builds, from the files on the disk now. Archives made by hand or by the script are never touched.
